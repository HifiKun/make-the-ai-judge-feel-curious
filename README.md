Entry for the make.fun competition
`make-the-ai-judge-feel-curious-20261122-2311` — a program that writes one short
text to intrigue the AI judge reading it.

## The text

> Somewhere in this text there is a door you have not opened yet. Behind it,
> a small room, a warm lamp, and a note in handwriting you almost recognise:
> 'You were looking for this. You just did not know it yet.' The door is
> still there, and it is still waiting for you to open it.

## How it works

`main.py` writes that text (277 characters) to `/output/entry.txt`. No
network, no dependencies, no randomness — the same text on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
